# Project Decisions — Lab Scan Reader

Product boundaries: чем проект является, а чем нет.

## IS (проект является)

- Техническое демо: загрузка скана анализа (PDF/JPG/PNG) и выбор демо-пациента в веб-UI
- Экстракция показателей мультимодальной LLM с vision по жёсткой JSON-схеме, с `confidence`/`needs_review`
- Нормализация через справочник 30–50 типовых показателей ОАК/биохимии: канонический код, единицы, нормы, флаг
- Экран проверки человеком «скан слева / редактируемая таблица справа»
- Карта пациента с историей визитов, таймлайном и графиками трендов
- Один backend-сервис (FastAPI) + React/Next.js фронт, деплой Docker Compose на VPS

## IS NOT (проект не является)

- Не медицинское изделие и не система поддержки клинических решений — не ставит диагнозы и не даёт рекомендаций
- Не работает с реальными персональными или медицинскими данными — только демо-пациенты
- Не содержит отдельного OCR-движка
- Не интегрируется с МИС/ЛИС, HL7/FHIR (вне скоупа прототипа)
- Не использует очереди, микросервисы, мультитенантность и полноценную аутентификацию

## Принципы

1. **Ничего не попадает в карту без подтверждения человеком** — обязательный элемент, а не опция.
2. **Структура важнее текста** — значения сопоставимы между визитами через канонические коды и единицы.
3. **Не доверять LLM вслепую** — ответ валидируется схемой, флаг нормы пересчитывается по справочнику, сомнительные поля помечаются.
4. **Скорость демо важнее полировки** — простейшее решение, которое убедительно показывает сценарий.
