# React / Next.js конвенции

## Правила

1. **TypeScript strict**: `.tsx`/`.ts`, без `any`; типы API-ответов синхронизированы с Pydantic-схемами backend
2. **Компоненты**: функциональные, `PascalCase.tsx`, один компонент — один файл, имена по домену (`ReviewTable`, `TrendChart`)
3. **Данные**: обращения к backend только через один API-клиент в `frontend/lib/api.ts`, не `fetch` из компонентов
4. **Состояние**: локальное через hooks; глобальный стор не вводить без явной причины в ТЗ
5. **Ревью-экран**: никаких действий записи в карту без явного клика «Подтвердить»; поля `needs_review` визуально выделены
6. **Пакетный менеджер**: `npm` в `frontend/`, lock-файл коммитится
7. **Проверки**: `npm run lint` и `npm run build` перед коммитом
