# pre-commit правила

## Правила

1. **Установка хуков**: `uv run pre-commit install` — выполнить один раз после клонирования
2. **Запуск вручную**: `uv run pre-commit run --all-files` — перед коммитом при сомнениях
3. **Не обходить**: не использовать `git commit --no-verify` без явного обоснования
4. **Конфиг**: `.pre-commit-config.yaml` в корне репозитория, версии хуков фиксированы
5. **Обновление**: `uv run pre-commit autoupdate` — при обновлении зависимостей
6. **Обязательные хуки**: `ruff-format` (форматирование) → `ruff` (линтинг) — в таком порядке
7. **Добавление хука**: новый хук обсудить, прописать в `.pre-commit-config.yaml`, зафиксировать rev
