# Правила тестов

## Правила

1. **Фреймворк**: `pytest` с `@pytest.fixture` для setup
2. **Структура**: `tests/` зеркало `src/` — `tests/unit/`, `tests/integration/`
3. **Название файлов**: `test_{module}.py`
4. **Название функций**: `test_{what}_{condition}_{expected}`
5. **Изоляция**: моки только для внешних API, внутренние модули — реальные
6. **Покрытие**: критичные пути ≥80%, целевые модули ≥90%
7. **Запуск**: `uv run pytest`
