# Escalation To Spec

Если apply-small-fix перестаёт быть маленьким, остановиться и направить в `plan-release`.

## Escalation Triggers

- нужен выбор архитектуры;
- появился новый public API, schema, protocol или migration;
- требуется больше одного логического этапа;
- ожидаемое поведение стало неоднозначным;
- изменение затрагивает несколько подсистем;
- targeted fix требует переписать тестовую инфраструктуру;
- исправление зависит от внешнего сервиса или rollout-плана.

## How To Stop

Сообщить кратко:

```markdown
Это уже не apply-small-fix: {причина}.
Нужен маршрут `plan-release`, потому что {риск/решение}.
Предлагаемый scope для ТЗ: {1-2 предложения}.
```

Не создавать временный spec внутри `apply-small-fix`.
