# Minimal Patch

Цель apply-small-fix — минимальное изменение, которое исправляет заявленный симптом.

## Patch Rules

1. Менять только файлы, нужные для фикса.
2. Не создавать `.ai/specs/*`.
3. Не делать попутный refactor.
4. Не менять публичные contracts без перехода в `plan-release`.
5. Не чинить unrelated замечания, найденные по пути.
6. Не переписывать тестовую инфраструктуру ради одного фикса.

## Work With Dirty Repo

Если есть чужие изменения:

- не трогать их;
- если они мешают фиксу, остановиться и спросить;
- если не мешают, работать только со своими файлами.

## Patch Summary

Перед проверкой зафиксировать:

```markdown
Changed files:
- `{path}` — {why needed}

Out of scope:
- {what was intentionally not touched}
```
