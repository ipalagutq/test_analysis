# Plan Mode Gate — apply-small-fix

`apply-small-fix` запускается только из Plan mode. Это защищает короткий no-spec маршрут от размытых задач.

## Required Plan Fields

Постановка должна содержать:

| Поле | Вопрос |
|---|---|
| Symptom | Что сейчас сломано или неудобно? |
| Expected behavior | Что должно стать иначе? |
| Scope | Какие файлы/зоны можно трогать и что не трогать? |
| Verification | Как понять, что фикс готов? |

## STOP

Остановиться, если:

- текущий режим не Plan mode;
- пользователь просит “быстро сделать”, но не сформулировал ожидаемое поведение;
- нет проверяемого критерия готовности;
- задача звучит как новая функциональность, а не исправление.

## Prompt Back

Если gate не пройден, попросить короткую постановку:

```markdown
Симптом:
Ожидаемое поведение:
Границы изменения:
Проверка готовности:
```
