# Env Sync

`.env` синхронизируется после проверки сервера и до build/up.

## Rules

1. Локальный `.env` должен существовать, если проект требует runtime secrets.
2. Копировать в `{APP_DIR}/repo/.env`.
3. Не выводить содержимое `.env`.
4. Если `.env` отсутствует, остановиться и попросить создать его, если проект не помечен как env-optional.
5. После копирования можно проверить только факт наличия файла и права доступа.

## Command Shape

```bash
scp -i {VPS_SSH_KEY} .env {VPS_USER}@{VPS_HOST}:{APP_DIR}/repo/.env
```

## Failure Handling

Если копирование не удалось:

- не запускать git pull/build;
- сообщить только destination path и тип ошибки;
- не печатать secrets;
- предложить проверить SSH key, пользователя и директорию.
