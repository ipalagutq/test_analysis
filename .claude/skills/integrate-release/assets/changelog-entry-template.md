# Changelog Entry Templates

## Spec Route

```markdown
## [{version}] — {date}

### {Added|Fixed|Changed} — {Feature Name}

{Краткое описание изменений.}

**Компоненты:**
- [{component}]({path}): {описание}

**Tests:** {X} passed
```

## Small-Fix Route

```markdown
## [{version}] — {date}

### Fixed — {Small Fix Summary}

{Краткое описание исправления без ссылки на spec.}

**Tests:** {X} passed
```
