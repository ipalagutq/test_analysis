# Lab Scan Reader

Прототип «ИИ читает сканы анализов и раскладывает показатели в карту пациента».

- **Загрузка** — веб-UI, drag&drop скана (PDF/JPG/PNG), выбор демо-пациента.
- **Экстракция** — скан целиком в vision-LLM (Claude) с жёсткой JSON-схемой: `{test_name_raw, value, unit, ref_range, flag}` + `confidence`/`needs_review`.
- **Нормализация** — справочник 30–50 показателей ОАК/биохимии: синонимы → канонический код, конверсия единиц, флаг выше/ниже нормы.
- **Проверка человеком** — «скан слева / редактируемая таблица справа», запись только после подтверждения.
- **Карта пациента** — SQLite/Postgres с демо-пациентами и историей, таймлайн и графики трендов.
- **Стек** — FastAPI (uv) + React/Next.js, Docker Compose на VPS.

Разработка ведётся по workflow — см. [CLAUDE.md](CLAUDE.md). Первый шаг: «создай ТЗ для …» (`plan-release`).
